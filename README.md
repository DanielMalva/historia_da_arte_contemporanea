# História da Arte Contemporânea · SENAC

Caderno estático da disciplina de Pós-graduação em Fotografia, ministrada por Daniel Malva em agosto e setembro de 2026.

O material usa Katy Hessel como leitura-base e inclui seis páginas de aula. O repositório publica apenas o caderno de apoio, imagens de obras utilizadas em contexto didático e seus créditos resumidos nas páginas. Não distribui o livro, os arquivos das apresentações ou PDFs da disciplina.

## Publicação

O repositório está preparado para GitHub Pages a partir da raiz da branch `main`.

Ao fim do curso, despublique o site em **Settings → Pages → Unpublish** e, se desejar, altere a visibilidade do repositório em **Settings → General → Danger Zone → Change repository visibility**.
